# TT-MAKER

เปลี่ยนเอกสารเป็นคลิป TikTok สไตล์ pixel 16-bit พร้อมเสียงพากย์ไทย ฟรีทั้งหมด
คุณส่งเนื้อหาให้ Claude แล้วได้ไฟล์ MP4 กับ caption กลับมา พร้อมโพสต์

## ทำเรื่องใหม่ (ขั้นตอนปกติ)

1. **เปิด Claude Code** บน repo นี้ จะใช้ cloud session หรือรันบนเครื่องตัวเองก็ได้ (ดู [เตรียมเครื่อง](#เตรียมเครื่อง-ครั้งแรกครั้งเดียว))
2. **แนบเอกสาร** (`.txt` / `.md` / `.pdf`) หรือวางเนื้อหาลงในแชต แล้วพิมพ์ว่า
   ```
   ทำคลิป
   ```
   ถ้ามีความต้องการเพิ่ม บอกไปพร้อมกันได้เลย เช่น "ทำคลิป เอาตอนเดียวพอ", "ใช้เสียงผู้ชาย", "เน้นตัวเลข"
3. **อ่านบทที่ Claude สรุปให้ในแชต** ซึ่งมีชื่อแต่ละตอนและทุกประโยคที่จะพากย์ แล้วเช็กว่า
   - เนื้อหาตรงกับต้นฉบับ ไม่มีข้อมูลที่ต้นฉบับไม่ได้พูด
   - ประเด็นสำคัญหรือข้อโต้แย้งไม่หายไป
   - hook ในประโยคแรกน่าดึงคนให้หยุดเลื่อน
4. **ตอบ `ok`** หรือสั่งแก้ก่อนก็ได้ เช่น "ตอน 2 ฉาก 3 พูดยาวไป", "เปลี่ยน hook ตอน 1 ให้เป็นคำถาม" Claude จะยังไม่ render จนกว่าคุณจะ ok
5. **รับไฟล์** ต่อตอนจะได้ `epN.mp4` (คลิป) กับ `epN.txt` (caption + hashtag)
6. **โพสต์ TikTok:**
   - อัปโหลด `epN.mp4`
   - copy ข้อความใน `epN.txt` ไปวางเป็น caption
   - เลือกเพลงจาก TikTok แล้ว**ลดเสียงเพลงให้เบา** เพราะในไฟล์มีแค่เสียงพากย์กับเสียงบลิป
   - เลือกปก: เฟรมแรกของคลิปถูกออกแบบมาให้เป็นปกอยู่แล้ว
   - ซีรีส์หลายตอน: โพสต์เรียงตามลำดับ และใส่ทุกตอนไว้ใน Playlist เดียวกัน

## สั่งแก้หลังได้คลิปแล้ว

พิมพ์บอก Claude ได้เลย เช่น

| อยากได้ | พิมพ์ว่า |
|---|---|
| แก้คำพูด | "ตอน 3 ฉากที่พูดเรื่องบัตรทอง เปลี่ยนเป็น ..." |
| แก้ภาพ | "ตอน 1 ฉากแรก ให้แมวตัวใหญ่ขึ้น และย้ายกระปุกไปทางซ้าย" |
| เปลี่ยนเสียงพากย์ | "ใช้เสียงผู้ชาย" (`th-TH-NiwatNeural`) หรือ "ใช้เสียงผู้หญิง" (`th-TH-PremwadeeNeural` ซึ่งเป็นค่าเริ่มต้น) |
| ของที่ไม่มีในคลัง | "วาดจรวดให้หน่อย" Claude จะวาด sprite เพิ่มไว้ในบทของเรื่องนั้น |
| render แค่บางตอน | "render ตอน 2 ใหม่" |

แก้แล้ว render ใหม่ได้เร็ว (ประมาณ 15 วินาทีต่อตอน) เพราะเสียงพากย์ของประโยคที่ไม่ได้เปลี่ยนจะถูกเก็บไว้ใน cache

## สิ่งที่ทำได้ / ทำไม่ได้

- **ฉาก:** มีให้เลือก 7 แบบ คือ ห้องเรียน, ห้อง, เมือง, ธรรมชาติ, อวกาศ, ออฟฟิศ และพื้นเรียบสำหรับตัวเลข
- **ตัวละคร:** แมว (คนเล่าเรื่อง ขยับปากตามเสียง), เด็ก และผู้ใหญ่ เปลี่ยนสีเสื้อ ผม และผิวได้ มี 6 ท่า: เฉย ๆ, ชี้, ตกใจ, คิด, ดีใจ, เศร้า
- **ไอคอน:** มีในคลัง 10 ชิ้น ของที่ไม่มีให้สั่ง Claude วาดเพิ่มได้ทุกเรื่อง
- **ความยาว:** ตอนละไม่เกิน 60 วินาที ถ้าเนื้อหายาว Claude จะแบ่งเป็นหลายตอนเอง
- **ทำไม่ได้:** ตัวละครเดินไปมา, กล้องซูมหรือแพน และเพลงประกอบในไฟล์

## เตรียมเครื่อง (ครั้งแรกครั้งเดียว)

**Cloud session (claude.ai/code):** ต้องเปิด network ให้เสียงพากย์ใช้ได้
1. ไปที่ environment settings → Network access → Allowed domains
2. เพิ่ม `speech.platform.bing.com`
3. ติ๊ก "Allow package managers" ไว้ด้วย

ถ้า session ไหนยังไม่มี `edge-tts` Claude จะติดตั้งให้เอง

**บนเครื่องตัวเอง:** ต้องมี Python 3.10 ขึ้นไป และ ffmpeg แล้วติดตั้ง dependency:
```bash
pip install -r requirements.txt
```

## รันเองโดยไม่ผ่าน Claude

ถ้าแก้ `series/<ชื่อเรื่อง>/script.json` เอง ใช้คำสั่งพวกนี้ได้

render ทุกตอน:
```bash
python3 render.py series/democratic-socialism/script.json
```

render เฉพาะตอนที่ 2:
```bash
python3 render.py series/democratic-socialism/script.json --ep 2
```

ตรวจว่าโค้ดยังทำงานปกติ:
```bash
python3 test_render.py
```

ไฟล์ที่ได้จะอยู่ใน `out/<ชื่อเรื่อง>/` ส่วนรูปแบบของ `script.json` ดูได้ใน [CLAUDE.md](CLAUDE.md)

## เจอปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| `TTS failed ...` หรือ `Cannot connect to host speech.platform.bing.com` | network ยังไม่เปิด (ดูหัวข้อเตรียมเครื่อง) หรือ edge-tts ล่มชั่วคราว ให้ลองใหม่ภายหลัง |
| `EPn: 63.2s is over 60s` | ตอนนั้นยาวเกิน บอก Claude ให้ย่อหรือแบ่งตอนเพิ่ม |
| `script.json errors: ...` | บทมีชื่อฉาก ท่า หรือ sprite ที่ไม่มีในคลัง ข้อความ error บอกตำแหน่งไว้ให้แล้ว และปกติ Claude จะแก้ให้เอง |
| เสียงพากย์หายทั้งหมดในวันหนึ่ง | edge-tts เป็นช่องทางที่ Microsoft ไม่ได้เปิดให้ใช้อย่างเป็นทางการ ถ้าโดนปิดถาวร ต้องเปลี่ยนไปใช้ TTS ตัวอื่น (ฟังก์ชัน `tts()` ใน `render.py`) |
